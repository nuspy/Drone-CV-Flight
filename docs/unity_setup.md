# Unity 6.5 integration

Full setup guide: [`unity/com.dronecv.flight/Documentation~/setup.md`](../unity/com.dronecv.flight/Documentation~/setup.md).

Summary:

1. Add the `unity/com.dronecv.flight` package to your Unity 6.x project
   (Package Manager → *Install package from disk*). It depends only on
   `com.unity.nuget.newtonsoft-json`.
2. Open the scene with your imported 3D environment (the environment import
   itself is handled by your existing external pipeline; the package only
   requires that the ground/buildings have **colliders**).
3. **GameObject > DroneCV > Create Sim Rig** builds the bridge hierarchy
   (SimLoop + GeoAnchorProvider + SunController + DroneBody + CaptureRig +
   MockLidar). Set the flyable-volume bounds, environment id, camera
   resolution/FOV/tilt (must match `configs/envs/<env>.yaml`) and assign the
   scene's directional light to the SunController.
4. Georeference the environment (dual mode): drop a `dronecv_geo.json`
   sidecar (embedded-metadata path) **or** create a GeoAnchorAsset fallback;
   with neither, Python falls back to the env YAML anchor.
5. Press Play and, from the repo:

```bash
dronecv protocol verify --host <unity-machine> --port 7601   # acceptance test
dronecv run-all --env unity_example                           # full pipeline
```

The Python pipeline is identical for Unity and the headless sim — same
protocol, same commands, same reports. EditMode tests inside the package pin
the C# frame conversions, solar ephemeris and message codec to the exact
values/bytes of the Python implementation (shared fixtures, regenerated by
`scripts/gen_protocol_fixtures.py`).
